LinuxMate - A Domain-Specific LLM Helper for Linux Commands & OS Lab Work

Operating Systems - Case Study

Students often forget the exact syntax of commands like ps, grep, chmod, kill, top and df. LinuxMate takes a plain-English question and returns a ready-to-use Linux command with a short explanation. In Concept mode it also answers short OS theory questions on processes, scheduling, deadlock and paging.

Objectives

  • Convert natural-language tasks into correct Linux commands with a one- or two-line explanation.
  • Give short, accurate OS-theory answers in Concept mode.
  • Attach a Warning to risky or destructive commands (rm -rf, mkfs, kill -9, chmod 777 ...).
  • Compare the plain model with the knowledge-assisted model on the same question.

How this version works

  • Data: OS-lab Q&A pairs in a structured dataset, grouped into 8 categories (process management, file & directory, permissions, disk usage, text processing, networking, shell utilities, OS concepts).
  • Retrieval: the most similar questions are matched and fetched for every user question.
  • Model: an Ollama model (llama3.2) receives those items as worked examples and answers in the fixed Command / Meaning / Warning template.
  • Safety: a risky-command check adds a Warning even if the model forgets it.
  • Fallback: if Ollama is offline, the best matching knowledge base answer is returned directly.

Tools

Python, Flask, Ollama (llama3.2), HTML/CSS/JavaScript.

Future work

RAG over the lab manual, LoRA fine-tuning of a small model such as Qwen2.5-0.5B-Instruct, stronger automated evaluation, command verification and voice input.

LinuxMate is a study helper. Always read a command before running it on a real system.
